# LOOP — 목표 추적 일기 (공개 버전)

로그인 없이 바로 사용하세요. 링크를 열면 자동으로 나만의 공간이 생깁니다.

> 데이터는 브라우저에 저장됩니다. 같은 브라우저에서 항상 내 데이터를 볼 수 있어요.

## 주요 기능

- 📅 **데일리 일기** — 오늘 한 일, 기분, 내일 할 일 기록
- 🎯 **목표 관리** — 연간/월간/주간 목표 설정 및 추적  
- 📊 **통계** — 목표 달성률, 기분 트렌드 확인
- 🔄 **회고** — 주간/월간/연간 회고 작성

## 사용 방법

1. 링크 접속하면 바로 시작 (가입/로그인 불필요)
2. **목표 설정** → 상단 "목표" 메뉴에서 연/월/주 목표 추가
3. **데일리 기록** → 매일 할 일 체크 + 하루 일기 작성
4. **회고** → 주간/월간/연간 돌아보기

> ⚠️ 같은 브라우저에서만 데이터 유지. 다른 기기에서는 새로 시작.
